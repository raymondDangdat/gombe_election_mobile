# INSTRUCTIONS ON HOW TO RUN THE PROJECT
1. Pull the app from GitHub
2. flutter clean
3. flutter pub get
4. install and start Ganache
5. run the app (flutter run)
6. Compile the contract using: truffle compile --reset
7. Deploy the contract to Ganache using: sudo truffle migrate or truffle migrate
